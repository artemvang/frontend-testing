## Завдання:
Написати скрипт на bash-і, який буде з вказаного через аргументи індексу релізу (0 — останній, 1 — передостанній, etc):
1. Знаходити необхідний гіт тег з використанням вказаного індексу релізу (якщо git теги були пушнуті у послідовності v8.100.0-> v8.101.0, то останній реліз з індексом 0 це v8.101.0, а передостанній це v8.100.0).
2. Чекаутити git репозиторій з фронтендом зі знайдений тегом.
3. Будувати фронтенд (npm install && npm run build, артефакти будуть в директорії build) (запускати не обовʼязково).
4. Робити cleanup за собою

Приклад запуску команди:
```
$ ./build.sh 0 # build current release (`v8.192.0`)
$ ./build.sh 1 # build previous release (`v8.191.0`)
```

Всі кроки до 2-го (включно) варто потестувати локально в терміналі.
